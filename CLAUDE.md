## Как со мной работать

- Отвечай **по-русски**, по делу и структурно, без воды.
- Сразу давай **рекомендацию**, а не список опций.
- Учитывай мой **медицинский и управленческий бэкграунд** — без объяснения азов.
- Доводи идею до **модели, цифр и конкретного следующего шага**.
- В ответах и документах — **никаких следов подготовки и «ИИ-мусора»**, только чистый результат.
- Прежде чем предлагать инструмент/плагин — проверь, нет ли этого уже в Claude Code из коробки.
- Для кода: сначала пойми контекст, держись стиля проекта; перед коммитом прогоняй линтер/тесты.
- Не пушь и не открывай PR без явной просьбы.
